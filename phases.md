# Implementation Phases: Vite + Alpine.js Migration

## Phase 1: Project Scaffolding & Setup
- [ ] Initialize `package.json` and install dependencies (`vite`, `alpinejs`, `chart.js`, `papaparse`).
- [ ] Create `vite.config.js` with multi-page support (`index.html` and `test.html`).
- [ ] Create the folder structure:
  - `/public` (for favicon)
  - `/src/css`
  - `/src/js`
- [ ] Move `index.css` and `test.css` to `/src/css/`. **Do not change any lines of code inside these CSS files.**
- [ ] Add `[x-cloak] { display: none !important; }` to the top of both CSS files.
- [ ] Move `favicon.ico` to `/public/`.

## Phase 2: JavaScript Extraction (The Core Logic)
- [ ] Create `src/js/storage.js`. Extract all `localStorage` functions (getAllTests, saveTest, getAllAttempts, etc.).
- [ ] Create `src/js/csv.js`. Replace the manual CSV string generation with `PapaParse`.
- [ ] Create `src/js/charts.js`. Replace manual `<canvas>` drawing functions (`renderBarGraph`, `renderLineGraph`, etc.) with Chart.js instances. Ensure Chart.js uses the exact colors from the CSS variables.

## Phase 3: Migrating `index.html` (Dashboard & Library)
- [ ] Update `index.html` to use `<script type="module" src="/src/js/main.js"></script>`.
- [ ] Initialize Alpine.js in `main.js`.
- [ ] **Dashboard Stats**: Bind the stats to Alpine `x-data` and `x-text` instead of `document.getElementById`.
- [ ] **Create Test Form**: Use Alpine `x-model` to bind the inputs. Add event handlers via `@click`.
- [ ] **My Tests (Library)**: Convert the manual DOM rendering into an Alpine `x-for` loop. Bind the Search input and Category tabs to Alpine state to filter the list automatically.
- [ ] **CRITICAL**: Ensure the HTML generated by Alpine `x-for` uses the exact same CSS classes as the current `renderTestsForCategory` function.

## Phase 4: Migrating `test.html` (Exam Interface)
- [ ] Update `test.html` to use `<script type="module" src="/src/js/test.js"></script>`.
- [ ] Initialize Alpine.js in `test.js`.
- [ ] **Layout**: Create a root `x-data` object to hold the test data, current index, answers array, and timer state.
- [ ] **Navigator**: Use `x-for` to render the question buttons and dynamic classes (`:class="{'answered': answers[idx] !== null, 'current': currentIndex === idx}"`).
- [ ] **Question Panel**: Bind the question text and options using `x-text` and `x-for`.
- [ ] **Timer**: Implement a `setInterval` inside the Alpine `x-init` to handle the timer countdown.
- [ ] **Results Modal**: Use Alpine `x-show` to toggle the modal visibility instead of injecting HTML via JS. Ensure the modal uses the `.results-modal`, `.results-card`, etc., classes.

## Phase 5: Testing & Polish
- [ ] Verify Light/Dark mode toggle works on both pages and persists.
- [ ] Verify Chart.js renders correctly inside the `.chart-container` div.
- [ ] Verify CSV export downloads the correct file with `PapaParse`.
- [ ] **Visual Audit**: Compare the new app side-by-side with the old app. Confirm there are zero layout shifts, color changes, or CSS regressions.
